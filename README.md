## 📖 About

NetScout helps authenticated students find authorized campus Wi-Fi networks and recommends the most suitable one based on their **location** and **measured network performance**. Access is limited to verified students through institutional email verification.

## ✨ Features

### Available now
- 🔐 **Student-only authentication**: registration with an institutional email (`@aust.edu`), email verification link, login, logout
- 💾 **Persistent sessions**: returning users skip straight to the home screen
- 👤 **Profile screen**
- 🔒 **Firestore security rules**: student data is restricted to verified students

### In progress / planned
- 🏫 Campus **regions** and their authorized **Wi-Fi networks** stored in Cloud Firestore
- ⚡ In-app **speed test** to measure real network performance
- 🎯 **Recommendations** that rank networks by location and measured speed
- 🛠️ **Admin platform** for campus admins to manage regions and networks

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)
- A Firebase project with **Authentication (Email/Password)** and **Cloud Firestore** enabled
- [Firebase CLI](https://firebase.google.com/docs/cli) and [FlutterFire CLI](https://firebase.flutter.dev/docs/cli)

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Daiyan-2004/NetScout.git
   cd NetScout
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Connect your own Firebase project**
   ```bash
   firebase login
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   This regenerates `lib/firebase_options.dart` for your project.

4. **Publish the Firestore rules** from your Firebase console (students collection only, restricted to the institutional email domain).

5. **Run the app**
   ```bash
   flutter run
   ```

## 🔐 Security Notes

- Only verified institutional emails can register and access the app.
- Firebase client config files are not secrets, but access is enforced by Firestore security rules.
- Never commit service-account keys, keystores, or `.env` files. They are listed in `.gitignore`.
